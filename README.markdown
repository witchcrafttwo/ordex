# ordex

**ordex** は、指定したフォルダを監視し、  
**キーワード** と **拡張子** の条件に一致したファイルを自動で別フォルダへ移動する  
Windows向けの自動ファイル振り分けアプリです。

JavaFXベースのGUIで操作でき、設定の保存、自動起動、バックグラウンド動作にも対応しています。

---

## 主な機能

- 監視フォルダの指定
- 保存先フォルダの指定
- キーワード条件の追加
- 拡張子条件の追加
- ルールの保存 / 読み込み
- ルール削除
- Windows自動起動のON / OFF
- システムトレイ常駐
- バックグラウンド起動対応

---

## 動作イメージ

1. 監視フォルダを選択
2. キーワードや拡張子を追加
3. 保存先フォルダを選択
4. ルールを追加
5. 対象ファイルが監視フォルダに作成されると、自動で保存先へ移動

たとえば、以下のような使い方ができます。

- `課題` を含むファイルを自動で課題フォルダへ移動
- `.pdf` を自動でPDF保管フォルダへ移動
- `.jpg` や `.png` を画像フォルダへ整理
- 条件はすべてANDです

---

## 起動方法
- `program files` 直下などの権限が厳しいところにインストールすると自動起動機能が動きません
- `user`などを活用してください

## アンインストール方法
- ダウンロードしたインストーラーを起動するとアンインストールする項目があります
- もしくは設定アプリからアンインストールを選択して消してください
